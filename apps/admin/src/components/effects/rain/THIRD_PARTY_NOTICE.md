# Codrops RainEffect attribution

This component is an application-specific TypeScript and React adaptation of
[RainEffect](https://github.com/codrops/RainEffect), created by Lucas Bebber for Codrops.

The original project permits integration and adaptation in personal and commercial projects, but
does not permit republishing, redistributing, or selling the original project as-is. See the
[Codrops licensing page](https://tympanus.net/codrops/licensing/) and the upstream README for the
full terms.

Adaptations in this project include typed lifecycle management, container resizing, cleanup,
application weather scheduling, and CMS login-page integration.
